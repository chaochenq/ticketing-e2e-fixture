# ticketing-e2e-fixture

A test fixture for Trent's local ticketing end-to-end run. The code here is
synthetic: each module holds small stand-in functions at the line ranges the
dev ticketing graph's fixed report cites as evidence, so filed tickets point at
real lines. Nothing here runs, and nothing here is a real credential.

`CODEOWNERS` assigns the paths to two fictional handles: one the Linear test
double resolves to a user, and one it does not.
